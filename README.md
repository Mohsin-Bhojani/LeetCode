# LeetCode Solutions

My solutions to [LeetCode](https://leetcode.com) problems.

## Workflow

```bash
# 1. Create a new problem (number, title, difficulty, [language])
./new.sh 1 "Two Sum" easy
# 2. Paste LeetCode's starter code into the file, solve it on leetcode.com
# 3. Save your accepted solution back into the file, then:
./push.sh
```

Supported languages: `swift` (default), `python`, `cpp`, `c`, `java`, `javascript`, `typescript`, `go`, `kotlin`, `rust`, `csharp`.
Run `./new.sh` again with another language to add a second solution to the same problem.
